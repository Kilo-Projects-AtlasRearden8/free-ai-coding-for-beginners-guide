# Free AI Coding for Beginners

A plain-English, step-by-step manual for learning to code with AI — completely free, with no account required for the models we recommend.

Written in the spirit of Dylan Asdale's *The Massive AI Manual*: AI explained "like a friend would," never condescending, always practical.

Published by **Asdale Dynamics, LLC** — Indiana, formed October 2026. Beginner-friendly AI education, books, and practical tools.

## What's inside

This guide walks you through, from zero:

1. [Introduction](docs/00-introduction.md) — who this is for and how to use it
2. [Getting Started: VS Code + Kilo Code](docs/01-getting-started.md) — install your tools
3. [Free Models, No Account](docs/02-free-models.md) — AI models that cost nothing and need no signup
4. [Reading AI-Written Code](docs/03-reading-ai-code.md) — how to read code an AI wrote, without trusting it blindly
5. [Fixing Errors](docs/04-fixing-errors.md) — read error messages, ask the AI for a fix, test again
6. [Terminal Safety](docs/05-terminal-safety.md) — run commands safely, avoid the dangerous ones
7. [When to Ask a Human](docs/06-when-to-ask-human.md) — know the edge of what AI can do
8. [First-Project Walkthrough](docs/07-first-project.md) — build your first AI-assisted project, step by step
9. [Glossary](docs/08-glossary.md) — plain-English definitions of the terms you'll meet

## How to read this guide

- **Markdown versions:** open the `.md` files in the `docs/` folder with any text editor or Markdown viewer.
- **Static website:** open `site/index.html` in your web browser. Nothing needs to be installed or served — it's plain HTML that works right off your hard drive.
- **Read in order** the first time through, then jump back to any chapter as a reference.
