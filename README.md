# Free AI Coding for Beginners

A plain-English, step-by-step manual for learning to code with AI — completely free, with no account required for the models we recommend.

Written in the spirit of Dylan Asdale's *The Massive AI Manual*: AI explained "like a friend would," never condescending, always practical.

Published by **Asdale Dynamics, LLC** — Indiana, formed October 2026. Beginner-friendly AI education, books, and practical tools.

## Who this is for

This guide is for anyone who wants to learn to code with AI — and do it for free.

You do not need a computer science degree. You do not need to pay for subscriptions. You do not need to create accounts with AI companies. You need a computer, an internet connection (to download the tools once), about an hour, and the willingness to try something new and make a few mistakes along the way.

It was written especially for:

- People who have never written code before
- People who have tried tutorials and gotten stuck
- Small-business owners, authors, and creators who want practical tools
- Healthcare workers and anyone else switching careers into tech
- Anyone who wants AI help that is local-first, private, and free

Nothing here is medical advice. If a chapter mentions healthcare, it is for education only. Talk to a qualified professional for medical decisions.

## How to read this guide

- **Markdown versions:** open the `.md` files in the `docs/` folder with any text editor or Markdown viewer.
- **Static website:** open `site/index.html` in your web browser. Nothing needs to be installed or served — it's plain HTML that works right off your hard drive.
- **Read in order** the first time through. Each chapter builds on the last. After that, use any chapter as a reference when you need it.

## Your first 10 minutes

1. Open `docs/00-introduction.md` and read the welcome.
2. Open `docs/01-getting-started.md` and install VS Code and the Kilo Code extension.
3. Open `docs/02-free-models.md` and try a free model that needs no account.
4. Open `docs/07-first-project.md` and build your first budget note card webpage.
