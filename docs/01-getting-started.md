# Getting Started: VS Code + Kilo Code

This chapter gets your tools ready. We'll install **VS Code** (a free code editor from Microsoft) and **Kilo Code** (a free AI coding assistant extension for VS Code). Together they let you write code, ask an AI for help, and run what you build — all in one place.

Everything in this chapter is free.

## Step 1: Install VS Code

1. Go to `code.visualstudio.com` in your web browser.
2. Download the installer for your computer (Windows, Mac, or Linux).
3. Open the installer and follow the prompts. Accept the defaults.
4. When it's done, open VS Code.

You should see a window with a sidebar on the left, a big empty area in the middle, and a bar along the bottom. That bottom bar area includes the **Terminal** — we'll use it later.

## Step 2: Install the Kilo Code extension

Extensions add extra features to VS Code. Kilo Code is the AI coding assistant we'll use throughout this guide.

1. In VS Code, click the **Extensions** icon in the left sidebar (it looks like four squares, one slightly separated) or press `Ctrl+Shift+X` (Windows/Linux) or `Cmd+Shift+X` (Mac).
2. In the search box at the top, type `Kilo Code`.
3. Find the Kilo Code extension in the results and click **Install**.
4. Wait for the install to finish. You may see a new Kilo Code panel appear in the sidebar.

If you can't find Kilo Code, make sure you're connected to the internet and try searching again. The extension marketplace is built into VS Code.

## Step 3: Open the Kilo Code chat

Once installed, Kilo Code usually adds a chat panel to VS Code:

1. Click the Kilo Code icon in the left sidebar (or open it from the VS Code command palette with `Ctrl+Shift+P` / `Cmd+Shift+P`, then type "Kilo Code: Open Chat").
2. A chat panel opens where you can type messages to the AI.

Type something like:

> "Hello! I'm new to coding. Can you help me build a simple webpage that says 'Hello, world'?"

You should get a friendly reply. That's your AI pair programmer.

## Step 4: Create your first folder

AI works best when it has a folder to work in:

1. In VS Code, choose **File > Open Folder** (or **Open...**).
2. Create a new folder somewhere easy to find, like `Documents/my-first-ai-project`, and open it.
3. The folder will appear in the Explorer panel on the left. It's empty for now — we'll fill it in the first-project walkthrough.

## How Kilo Code helps

Kilo Code can:

- Write new files based on what you describe
- Explain code that's already in your files
- Suggest fixes when something breaks
- Run commands in the terminal for you (with your approval)

You stay in charge. Kilo Code makes suggestions; you decide whether to accept them.

## If something goes wrong

- **Extension won't install:** Check your internet connection and try again. Restart VS Code and try once more.
- **Kilo Code panel doesn't show:** Use the command palette (`Ctrl+Shift+P` / `Cmd+Shift+P`) and search "Kilo Code".
- **You're asked to sign in:** Some features may prompt for an account. You can skip sign-in and still use free models — see the next chapter.
