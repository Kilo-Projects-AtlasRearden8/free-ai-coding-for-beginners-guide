# Introduction

Welcome. This guide is for anyone who wants to learn to code with AI — and do it for free.

You do not need a computer science degree. You do not need to pay for subscriptions. You do not need to create accounts with AI companies. You need a computer, an internet connection (to download the tools once), about an hour, and the willingness to try something new and make a few mistakes along the way.

This guide was written by **Asdale Dynamics, LLC** in the spirit of Dylan Asdale's *The Massive AI Manual*: AI explained "like a friend would" — plain English, step by step, never condescending. Dylan Asdale is a registered nurse turned AI author and founder of Asdale Dynamics, LLC (Indiana, formed October 2026). If he can go from healthcare to writing about AI, you can go from wherever you are to writing code with AI.

## What you'll learn

By the end of this guide you will be able to:

- Install VS Code and the Kilo Code AI coding assistant
- Use AI models that are free and need no account
- Read code an AI wrote and understand what it does
- Fix errors when AI-written code doesn't work
- Use the terminal safely
- Know when to stop and ask a human for help
- Build your first real project with AI, step by step

## Who this is for

This guide was written for beginners — specifically:

- People who have never written code before
- People who have tried tutorials and gotten stuck
- Small-business owners, authors, and creators who want practical tools
- Healthcare workers and anyone else switching careers into tech
- Anyone who wants AI help that is local-first, private, and free

Nothing here is medical advice. If a guide mentions healthcare, it is for education only. Talk to a qualified professional for medical decisions.

You will not be talked down to here. Learning to code feels awkward at first for everyone — including people who now do it for a living.
