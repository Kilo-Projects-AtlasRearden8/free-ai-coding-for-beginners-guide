# First-Project Walkthrough

Let's build something real together. We'll make a simple **budget note card** — a single webpage where you can type an expense and see a running total. It's free, runs in your browser, and needs no server.

This walkthrough uses VS Code, Kilo Code, and only free tools.

## What we're building

A single HTML file that:
- Has a box to type an expense amount
- A button to add it
- Shows a running total
- Works entirely in your browser

## Step 1: Set up the folder

1. Open VS Code.
2. Choose **File > Open Folder**.
3. Create a folder named `my-first-budget` somewhere easy (like `Documents`).
4. Open it.

You should see an empty Explorer panel on the left.

## Step 2: Ask Kilo Code to create the page

Open the Kilo Code chat panel and send this message:

> "I'm a beginner. Please create a single HTML file called index.html with a simple budget note card. It should have an input for an expense amount, an Add button, and a running total display. Use only HTML, CSS, and JavaScript in one file. Keep it simple and add comments explaining each part. Make it look clean and friendly."

Kilo Code will suggest a file. Review it (read the chapter on reading AI-written code first if you like), then accept it or copy the code into a new file named `index.html` in your folder.

## Step 3: Read the code

Open `index.html` and read it top to bottom. Look for:

- The input box where you type a number
- The button that adds the expense
- The place where the total is shown
- The comments explaining each part

If anything is unclear, ask Kilo Code: "Can you explain this part line by line?"

## Step 4: Open it in your browser

In VS Code, right-click `index.html` in the Explorer and choose **Open with Live Server**, or just find the file in your file manager and double-click it. It opens in your web browser.

Try it:
1. Type a number (like `12.50`) into the input.
2. Click Add.
3. Watch the total update.
4. Add another expense.

It works. You built it with AI.

## Step 5: Intentionally break it and fix it

Delete the line that updates the total. Save. Refresh the browser. Notice the total no longer changes. Now ask Kilo Code:

> "My budget page stopped updating the total when I add an expense. Here's the code: [paste it]. Can you fix it?"

Apply the fix, save, refresh. It works again. You just debugged.

## Step 6: Make it yours

Ask Kilo Code to add one small feature — for example, a button to clear the total, or a label showing today's date. Read the change, apply it, test it. This is how you go from following a walkthrough to making your own projects.

## What you just did

You installed tools, used a free AI model, wrote code with AI, read it, ran it, broke it, fixed it, and extended it. That's the whole cycle of coding with AI.
