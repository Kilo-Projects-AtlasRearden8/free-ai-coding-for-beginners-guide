# Glossary

Plain-English definitions for the terms you'll meet in this guide. If you see a word that isn't here, ask Kilo Code to explain it — or add it to your own list.

**AI (Artificial Intelligence)** — Software that can do things that usually require human thinking, like writing, summarizing, or coding.

**API** — A way for two programs to talk to each other. You usually don't need to touch an API directly when using free local models.

**Commit** — Saving a snapshot of your project in git so you can return to it later.

**Context window** — How much text an AI can "remember" at once while chatting. Very long conversations can make it forget earlier parts.

**CSS** — A language that styles webpages (colors, fonts, spacing). Used with HTML.

**Extension** — A plugin that adds features to VS Code. Kilo Code is an extension.

**Git** — A tool that tracks changes to your files over time, so you can undo mistakes and see history.

**Hallucination** — When an AI states something confidently that isn't true. Always double-check important facts and code.

**HTML** — The language used to build webpages.

**Kilo Code** — A free AI coding assistant extension for VS Code that helps you write, read, and fix code.

**LLM (Large Language Model)** — The kind of AI behind chatbots and coding assistants. It predicts text one piece at a time.

**Local-first** — Keeping your data and processing on your own computer instead of sending it to a company's servers. Private and works offline.

**Markdown** — A simple way to format text (like this guide) using symbols such as `#` for headings.

**Model** — The actual AI program that generates answers. Different models have different strengths.

**Repository (repo)** — A folder tracked by git, often shared online.

**SDK** — A set of tools for building software for a particular platform. You don't need one for this guide.

**Shell** — The program that reads your terminal commands. Examples: bash, PowerShell, zsh.

**Source code** — The human-written instructions that make up a program.

**Syntax error** — A mistake in the grammar of a programming language, like a missing bracket or quote.

**Terminal** — A text-based way to control your computer by typing commands.

**Token** — A chunk of text (a word or part of a word) that an AI reads or writes. Models are often priced or limited by tokens.

**VS Code** — A free code editor from Microsoft. The app where you'll write code and use Kilo Code.
